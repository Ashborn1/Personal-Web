# John Zyrus B. Ubay — Game Developer Portfolio

A modern, high-performance personal portfolio website designed for an aspiring **game developer**, featuring a sleek sci-fi inspired UI, animated floating code background, and a fully responsive bottom navigation dock.

> **Tagline:** _Crafting Worlds Through Code._

---

## 📖 Overview

This is a single-page application (SPA) style portfolio built with **vanilla HTML, CSS, and JavaScript** — no frameworks, no build tools, and no dependencies required. It presents five distinct sections (Home, About, Projects, Gallery, Contact) inside one smooth, animated interface with a floating bottom navigation bar reminiscent of modern game launchers and mobile OS interfaces.

The design language blends **premium glassmorphism**, **neon accents**, and **subtle ambient animations** to create an immersive, professional developer showcase.

## ✨ Features

### Design & Aesthetics
- **Futuristic Sci-Fi Theme** — Deep space navy background with cyan, magenta, and purple ambient gradients.
- **Animated Floating Code Background** — Lightweight, GPU-accelerated code snippets drifting upward for developer atmosphere.
- **Glassmorphism Cards** — Frosted glass panels with soft borders, glowing hover states, and smooth lift animations.
- **Gradient Typography** — Eye-catching gradient text on hero headings.
- **Premium Noise Texture** — A subtle SVG noise overlay for depth and a high-end finish.

### Functionality
- **Single Page Application (SPA)** — Instant page switching with no reloads, powered by vanilla JavaScript.
- **Floating Bottom Navigation Dock** — Modern, thumb-friendly navigation with glowing active states.
- **Contact Form Simulation** — Interactive transmission feedback with animated button states.
- **Parallax Hero Image** — Subtle 3D tilt effect on the profile card following the cursor.
- **Responsive Design** — Optimized for desktop, tablet, and mobile devices.

### Performance & UX
- **Zero Dependencies** — No React, Vue, jQuery, or build tools.
- **Mobile Optimized** — Hardware-accelerated animations (`translate3d`), reduced `backdrop-filter` cost, and no layout thrashing.
- **Image Drag Prevention** — Globally disables image dragging for a polished app-like feel.
- **Tap Highlight Removed** — Clean touch interactions on mobile.
- **Accessibility Friendly** — Semantic HTML, clear focus states, and readable contrast.
